# 紫薇 PNG 序列帧资源

将透明 PNG 放进对应状态目录，并保持 `manifest.json` 中的路径与文件名一致。建议首批素材统一为 512×512 px、透明背景、同一画布中心和相同人物比例。

状态目录：

- `idle/`：默认待机循环，3 张关键帧
- `tap-reaction/`：点击反馈，2 张过渡帧
- `phone-enter/`：拿出玉简，2 张过渡帧
- `phone-loop/`：持续查看玉简，当前使用 1 张稳定持玉简帧；眨眼帧待重新生成
- `phone-exit/`：收起玉简，2 张过渡帧

资源缺失时页面会显示“待接入正式透明素材”占位，不会回退到 CSS 人物。
