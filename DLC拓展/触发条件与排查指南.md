# 道渊 DLC 触发条件与排查指南

> 适用版本：道渊小手机 V0.9（万年仇怨 / 合欢宗·百花谷 / 洛阳 / 蜀山剑门）
>
> 本文描述当前正式源码的真实判断逻辑。DLC 不通过 EJS 激活，也不会覆盖角色主世界书；脚本只控制四本附属世界书条目的启用状态，酒馆随后再按条目自身的常驻/关键词规则决定是否注入模型。

## 1. 实际触发链

一次成功触发必须依次满足：

1. 目标世界书已经存在。
2. 世界书已经挂载到当前角色的附属世界书。
3. DLC 总开关已开启，并点击“保存并应用 DLC 开关”。
4. 世界书状态不是“缺失条目”“重名冲突”或“发现多个候选世界书”。
5. `stat_data.主角.境界` 或 `stat_data.世界.当前地点` 满足该 DLC 的自动控制条件。
6. 对于绿色关键词条目，最近聊天内容还必须命中该条目的关键词；蓝色常驻条目不需要这一步。
7. 世界书扫描预算足够，且酒馆本轮确实重新执行了世界书扫描。

简化表示：

```text
已安装 → 已附属挂载 → DLC 开关开启
  → 脚本根据境界/地点启用条目
  → 酒馆根据蓝灯/绿灯与关键词注入条目
```

## 2. 脚本读取的数据

脚本只读取最新消息楼的以下字段：

```text
stat_data.主角.境界
stat_data.世界.当前地点
```

排查时应先确认状态栏/MVU 中的实际值，而不是只看正文写了“我来到百花谷”。如果正文变化没有同步到 `stat_data.世界.当前地点`，地点 DLC 不会切换。

四本 DLC 默认总开关全部为关闭。关闭某本总开关时，该世界书所有条目都会被脚本设为禁用。

## 3. 万年仇怨

### 3.1 总体规则

- 自动控制来源：`stat_data.主角.境界`。
- 进程只前进、不自动倒退：脚本会取“境界对应进程”和“当前已经开启的最高进程”中的较高值。
- 五个进程条目始终只有当前最高进程启用。
- 已解锁的机关、历史和人物条目随进程逐步开放。
- 未列入阶段表的普通条目保持原世界书默认启用状态。

### 3.2 境界与进程

| 主角境界包含 | 当前进程 |
|---|---|
| 筑基 | 进程一：萌动 |
| 金丹 | 进程二：爆发 |
| 元婴、化神 | 进程三：升华 |
| 炼虚 | 进程四：灾劫 |
| 合体、大乘、渡劫 | 进程五：疯嚣 |
| 无法识别或低于筑基 | 不由境界新开启进程 |

### 3.3 逐步解锁

- 进程一：天华帝国历史、疯帝·瑕、血肉机关生成、血傀。
- 进程二：血巢。
- 进程三：毕方、相柳、蠃鱼、白泽、梼杌。
- 进程四：穷奇、饕餮、混沌、共工、祝融。
- 进程五没有额外解锁表项，但会启用最高阶段规则。

南境长城现在只使用 `南境长城`、`守集城`、`南境防线` 作为关键词，不会因为普通提到“南离火洲”而触发。

### 3.4 推荐测试语句

```text
我当前境界为筑基期，听闻南境防线近日出现异动，决定前往南境长城的守集城调查。
```

先确认 `stat_data.主角.境界` 已变成包含“筑基”的文本，再查看“进程一：萌动”是否启用。

## 4. 合欢宗·百花谷

### 4.1 总体规则

- 自动控制来源：`stat_data.世界.当前地点` 是否包含 `百花谷`。
- 进入百花谷：百花谷设施、身体改造、物价、任务、地点和群体设定等地点条目启用。
- 离开百花谷：上述地点条目关闭，减少无关 token。
- 人物、极乐宫、合欢宗组织、日常等非地点条目保持其原世界书默认启用状态；其中绿色条目仍需关键词命中。

### 4.2 进入地点后仍未显示绿灯

“允许自动控制”只代表脚本可以启用条目，不代表所有绿色条目立即激活。比如“人物详情：梦青”还需要聊天扫描区出现 `梦青`、`听雨居` 等关键词。

脚本控制的百花谷地点条目包括：百花谷总设定、百花坊、芳华集、流芳津、烟霞街、迎春馆、流觞苑、霓裳台、镜花园、流霞台、照影间、流香院、听雨居、玉露泉、锁心堂、摘星楼、欲湖、沉香窟、绮梦阁，以及改造、道具、物价、任务、位置、活动和群体规则。

### 4.3 推荐测试语句

```text
我已经抵达百花谷，先去百花坊登记身份，再前往听雨居拜访梦青。
```

应先确认当前地点字段实际包含“百花谷”。随后：

- 百花谷地点条目应被启用；
- `听雨居`、`梦青` 等关键词条目应在酒馆扫描后激活；
- 仅仅打开世界书编辑页，不会代替一次生成前扫描。

## 5. 洛阳

### 5.1 总体规则

- 自动控制来源：`stat_data.世界.当前地点` 是否包含 `洛阳`。
- 包含“洛阳”：20 条全部启用。
- 不包含“洛阳”：20 条全部关闭。
- 其中常驻条目在启用后直接参与世界书注入；关键词条目仍需命中，例如 `神策军`、`镇魔司`、`禁武令`、`黑暗动乱`。

### 5.2 推荐测试语句

```text
我进入神都洛阳，准备前往镇魔司打听禁武令与黑暗动乱的消息。
```

确认当前地点包含“洛阳”后，再进行一次生成或刷新世界书扫描状态。

## 6. 蜀山剑门

### 6.1 总体规则

蜀山采用“地点基础条目 + 峰脉精确条目 + 关键词详情”的混合控制。

只要当前地点包含以下任一标记，就视为处于蜀山范围：

```text
蜀山、飞霜峰、镇岳峰、凌虚峰、抱朴峰、冲霄峰、无我峰、青石坊、锁妖塔
```

### 6.2 基础条目

进入蜀山范围时启用：

- 叙事基调
- 入门登记
- 日常课程与修炼
- 年度大事
- 部门总纲
- 蜀山剑门（增量设定）
- 各峰特化

离开蜀山范围时，上述基础条目关闭。

### 6.3 六峰条目

具体峰条目只在当前地点包含该峰名称时启用：

- `飞霜峰` 只开启飞霜峰；
- `镇岳峰` 只开启镇岳峰；
- `凌虚峰` 只开启凌虚峰；
- `抱朴峰` 只开启抱朴峰；
- `冲霄峰` 只开启冲霄峰；
- `无我峰` 只开启无我峰。

仅写“蜀山剑门”不会同时打开六峰详情，避免一次注入全部峰脉。

### 6.4 人物与场所详情

姜梦、同门雅集、宿舍、青石坊、锁妖塔、每日事件等条目保持原世界书默认启用状态，并继续依靠自身关键词触发。

修订后的姜梦 DLC 条目只补充外观和性格，原版世界书中的境界、峰主身份、宗门地位和“四行缺火”优先。

### 6.5 推荐测试语句

```text
我抵达蜀山剑门，随后前往无我峰拜访峰主姜梦，请教无我剑诀。
```

预期：蜀山基础条目启用、无我峰启用、其他五峰关闭；生成前扫描命中 `姜梦` 后，姜梦增量条目激活。

## 7. 按钮与触发的关系

| 按钮 | 会做什么 | 不会做什么 |
|---|---|---|
| 保存并应用 DLC 开关 | 保存四本总开关，并立即按当前境界/地点同步条目启停 | 不创建或挂载世界书 |
| 创建不存在的 DLC 世界书 | 只创建完全不存在的 DLC 世界书 | 不挂载已有世界书，不覆盖同名书 |
| 挂载已有 DLC 到当前角色 | 将已存在但未挂载的 DLC 加入当前角色附属世界书 | 不创建条目，不替换主世界书 |
| 补回缺失的世界书条目 | 只追加名称缺失的条目 | 不覆盖已存在正文；发现重名时不会修复 |
| 刷新 DLC 状态检查 | 重新读取世界书、条目数和挂载状态 | 不主动修改条目 |

## 8. 快速排查顺序

1. 点击“刷新 DLC 状态检查”。
2. 确认不是“未安装”“未挂载”“缺失/重名”“多个候选世界书”。
3. 确认对应 DLC 开关已勾选，并点击“保存并应用”。
4. 直接查看 `stat_data.主角.境界` / `stat_data.世界.当前地点` 的真实值。
5. 检查目标条目左侧是否已经启用；灰色代表脚本条件未满足或尚未同步。
6. 若条目已启用但没有绿灯，检查它是否为关键词条目，并在最新聊天中明确写出关键词。
7. 发送一条消息或触发一次重新生成，让酒馆重新扫描世界书。
8. 如果刚切换过附属世界书，先点击刷新状态；仍异常时刷新酒馆页面，再确认条目数量没有变化。

## 9. 典型异常判定

### 世界书有条目，但全部灰色

- DLC 总开关未保存；或
- 境界/地点字段不满足；或
- 当前世界书被诊断为不兼容，脚本为保护数据跳过自动修改。

### 条目已经启用，但没有激活指示

- 该条目是绿色关键词条目，尚未命中关键词；或
- 酒馆还没有重新执行生成前扫描；或
- 世界书 token 预算不足。

### 点击“只补缺失条目”后正文仍是旧版本

这是预期的数据保护行为。“只补缺失”不会覆盖同名既有条目，也不会把手动修改恢复成内置版本。

### 刷新页面后条目消失

不属于正常触发问题。立即停止重复安装，检查世界书是否出现 0 条、是否存在同名候选书，并保留现场后再排查。当前脚本已包含“空快照拒绝整本回写”和“状态未变化不保存”的保护，但仍应先确认目标酒馆运行时版本与世界书 API 状态。
