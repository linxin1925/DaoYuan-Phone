# 道渊小手机 V1.1 使用与发布说明

## 导入

在 SillyTavern 的酒馆助手“脚本”页导入 `releases/道渊小手机V1.1.json`，目标选择全局脚本库。脚本 ID 与旧版相同，允许覆盖升级；它是酒馆助手脚本，不是角色卡。

## V1.1 范围

V1.1 完整保留 V1.0 的玉简、仙网、万宝商行、MVU 数据桥接及四本 DLC 管理功能，只替换桌宠媒体与交互状态机。播放器使用两个透明 WebM `<video>` 交叉切换，首期只有五个动作：`Idle`、`TapReaction`、`PhoneEnter`、`PhoneLoop`、`PhoneExit`。

玉简退出可被新点击打断。兼容接口 `window.openJadeUI()` 与 `window.closeJadeUI()` 保留。随机动作、转向、角色拖拽行为扩展和屏幕漫游不在 V1.1 范围内。

V1.1 导入包同时内置“道渊正文美化·修仙小说阅读器 V26 正式版”。正式对白协议为 `{角色标准姓名}“台词”`，并继续兼容旧 `<dialogue>` 与 `<!-- speaker:... -->`。正文美化继续扫描宿主文档中的 `.mes_text content, content`，用于兼容预设、模型或渲染链产生的非标准 `<content>` 位置；不得擅自收窄为聊天区选择器。阅读器右上角“阅”按钮仍独立管理字体、字号和术语注解，术语注解默认关闭，只有用户开启时才联网加载组件。

当前内置的是 SHA-256 为 `43e57a3f2b29596f2363d1657857d77b56e3aee31f9d4967aab9f40aa585773d` 的最新 V26 正式构建。对白卡使用左侧小型长方形立绘、右上姓名和右下台词的紧凑布局；台词保持普通块级文本流，避免术语注解插入后破坏句子排版，并增强了宿主主题下的样式作用域。

小手机“设置”首页提供“正文美化 V26”总开关，默认开启。关闭后会立即停止观察器和新正文处理；已经完成 DOM 转换的旧楼层不会被冒险反向改写，刷新酒馆页面后会按关闭状态保留原始正文。重新开启会立即启动 V26 并扫描页面中现有的 `<content>`。

## 桌宠尺寸与点击范围

小、中、大会同时改变外层布局尺寸、视频舞台和角色命中层。WebM 本身是宽幅透明画布，因此整张视频不能作为点击区：外层按钮与舞台均不接收指针事件，只有舞台中央约 40% 宽的角色活动区接收点击和拖拽。

## 验证状态

- 已通过 TypeScript 类型检查、Vite 生产构建、导入 JSON 结构检查和 V1.0 全量自动回归。
- 打包流程会校验 V26 上游快照的稳定 ID 与 SHA-256，再把原始脚本放入受总开关控制的启动器；不会重写 V26 的扫描或术语开关行为。
- Chrome 中的真实 SillyTavern 已测得旧实现最小尺寸外层按钮为 `101×121px`、角色窄命中层约 `54×153px`，据此确认了“左侧空白仍可点击”的根因。
- 根因修正为外层按钮 `pointer-events: none`、角色伪命中层 `pointer-events: auto`。该最终包仍需导入目标酒馆后人工确认人物本体可点、左右透明区不可点、关闭后立即重开可用。
- 内置 V26 仍需在真实酒馆确认：新旧对白协议都能生成正确人物卡；标准及非标准位置的 `<content>` 均能美化；术语默认关闭；开启、刷新、关闭和跨楼层同步正常；没有重复阅读器或重复监听器。
