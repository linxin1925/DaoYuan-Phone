# 道渊小手机

面向 SillyTavern 的道渊世界观内嵌手机前端。当前正式版本为 **V1.1**，正式导入文件为 `releases/道渊小手机V1.1.json`。

## 功能

- DSH 透明 WebM 桌宠、五动作玉简开合状态机与手机比例悬浮界面
- 内置带小手机总开关的 V26 正文美化阅读器；支持 `{角色标准姓名}“台词”` 对白协议、兼容非标准 `<content>` 输出，并保留独立、默认关闭的联网术语注解开关
- 玉简联系人、主动传讯、正文玉简通信解析与旧状态栏记录导入
- 万宝商行 AI 货单、批量估价、买卖交易、交易记录与受限 MVU 写回
- 绝色榜、仙网风闻、论坛和天机日报
- MVU 世界时间、地点、人物关系、储物袋和地图只读展示
- 主线信息注入开关、仙网重 Roll 兼容及楼层删除后的数据对账
- 万年仇怨、合欢宗·百花谷、洛阳、蜀山剑门四本独立 DLC 世界书的安装、附属挂载、缺失修复与自动启停
- 桌面浏览器与手机浏览器的基础适配；更细的长期 UI 重构计划见 [ROADMAP](./ROADMAP.md)

> 使用建议：V1.1 已完成离线验证和正式构建；桌宠最终窄命中区仍需在目标 SillyTavern 中完成人工点击验收。遇到问题请记录设备、浏览器、SillyTavern 版本、桌宠尺寸和操作步骤。

## 使用

下载 [`releases/道渊小手机V1.1.json`](./releases/道渊小手机V1.1.json)，在 SillyTavern 的酒馆助手脚本库中导入；稳定脚本 ID 会覆盖升级旧版本。V1.1 说明见 [V1.1 使用与发布说明](./docs/V1.1使用与发布说明.md)，后续开发先读 [NEXT](./NEXT.md)。

## 本地开发

要求 Node.js 与 pnpm。`app/` 是唯一权威源码工程。

```bash
cd app
pnpm install
pnpm check
pnpm package:formal
```

`pnpm check` 会执行类型检查、数据样例校验、界面契约校验、生产构建和候选包生成。
